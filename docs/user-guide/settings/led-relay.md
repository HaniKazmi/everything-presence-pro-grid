# LED and relay

Configure the front LED and the relay output. This page will cover:

**LED**

- Four modes: **Occupancy**, **Environmental** (CO2), **Environmental + Occupancy**, **Manual Control**.
- Brightness and the occupancy colour.
- Enabling or disabling the internal SEN0609 indicator LED independently.

**Relay**

- Trigger source: **disabled**, **motion**, **presence**, or **occupancy**.
- Contact mode: normally open or normally closed.
- Wiring reference: see the [hardware overview](https://docs.everythingsmart.io/s/products/doc/hardware-overview-gqc0XAh0e5).
