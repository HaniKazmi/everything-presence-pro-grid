# Logging

Per-component log levels for both the device firmware and the Home Assistant integration. Raise a component's log level when debugging; leave everything at default in normal use. This page will cover:

- The log-level options (default, info, debug, verbose).
- Which components you can adjust independently (zone engine, reporting, ESPHome API, integration layers).
- Where the resulting logs appear (HA logs, device console, panel).
- Resetting to defaults.
