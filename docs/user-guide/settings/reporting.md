# Reporting

How often the device publishes data to Home Assistant. Lower intervals = more responsive automations but more network and HA traffic; higher intervals = quieter network but slower updates. This page will cover:

- Target entity interval (raw LD2450 coordinates, when enabled).
- Zone entity interval (per-zone presence and target count).
- Which entity categories stream continuously vs only-when-changed.
- Sensible defaults for most rooms.
