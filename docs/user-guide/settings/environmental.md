# Environmental

Offsets that correct the temperature and humidity readings for the heat the device generates and for typical ceiling/corner mounting. This page will cover:

- **Temperature offset** — degrees to subtract from the SHTC3 reading.
- **Humidity offset** — percentage points to adjust the SHTC3 reading.
- How to calibrate the offset against a reference thermometer or hygrometer.
- Why a single fixed offset is only a rough correction — see [Hardware → Environmental sensors](../hardware.md#environmental-sensors).
