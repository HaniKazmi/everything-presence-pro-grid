# Entities

Grid's approach to entities is opt-in: most of what the firmware is capable of publishing stays disabled in Home Assistant until you enable it. This page will cover:

- The full list of entities the firmware exposes.
- How to enable or disable each entity from the panel.
- How to rename the structural parts of entity names while keeping the user-provided parts intact.
- The trade-offs — when to enable raw target coordinates, motion/static presence, per-zone target counts.
