# Developers

This section is for contributors and anyone working on the Everything Presence Pro Grid codebase itself. It covers how the system is put together, how data flows between firmware, the Home Assistant integration, and the frontend panel, and how to set up a development environment.

If you are looking for end-user documentation — installation, calibration, zone setup — check the **User Guide** tab *(being added in the next step)*.

- **[Architecture](architecture.md)** — the three layers (firmware, HA integration, frontend) and how they communicate.
- **[Data catalog](data-catalog.md)** — entity naming, per-device config storage, and data flow reference.
- **Code layout** — repo structure walkthrough *(coming in the next step)*.
- **Contributing** — dev setup, test expectations, PR process *(coming in the next step)*.
